# RTA Dashboard Demo

Clean-room static demo dashboard for realtime contact center analytics wallboard scenarios.

This public version uses generated sample metrics and does not include private repository source code or internal service integrations.

## Run locally

Open `index.html` directly, or serve the folder:

```bash
python3 -m http.server 8080
```

## GitHub Pages

The site is designed to run from the repository root with GitHub Pages.
